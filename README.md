# VxraV2-ST

VxraV2-ST is a rebranded, portable distribution of SillyTavern packaged with:

- Portable Node.js runtime (bundled)
- Custom `VxraST.exe` launcher with embedded WebView2 browser
- VxraV2 dark theme and branding
- Zero external dependencies — unzip and double-click

## Installation

Use the [VxraV2 Installer](https://github.com/YOUR_USER/VxraV2) — it downloads and extracts everything for you.

## Manual install

1. Download `VxraV2-ST-v1.0.0.zip` from the [latest release](../../releases/latest).
2. Extract to any folder.
3. Run `VxraST.exe`.
